About Folio

A student task management system built as a front-end college project — one consistent theme, from the loading screen to the last footer link.

What Folio is

Folio is a dashboard for keeping every academic responsibility — assignments, exams, class timetables and long-term progress — in one place, styled after a scholar's personal ledger rather than a generic to-do app.

Why it exists

Students juggle deadlines across many subjects and tools. This project explores what a single, calm, well-organized home for that information could look like, built with HTML, CSS, JavaScript and React.

Main features

Task ledger

Priority, difficulty, due dates and category tags for every task.

Weekly timetable

Classes, labs, exams and study sessions on one grid.

Subject overview

Instructor, credits and progress per course.

Exam countdowns

Know exactly how many days are left, and how ready you are.

Progress dashboard

Completion rings, weekly bar charts and exam-prep tracking.

Saved in your browser

Add, tick off, filter and delete tasks — everything is remembered when you come back.

Benefits for students

  • — One place to see everything due this week, instead of five different apps.
  • — Visual priority and difficulty cues make planning faster.
  • — A progress view that turns effort into something you can actually see.

Technologies used

HTML5 CSS3 CSS Grid & Flexbox JavaScript React localStorage Responsive design

Login, tasks, events and progress are handled with JavaScript and saved in the browser using localStorage. The dashboard (home page) is built with React.
